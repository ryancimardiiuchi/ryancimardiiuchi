### 🧺 Lavô+

**Sistema de lavanderia online**

Projeto full-stack desenvolvido para gerenciamento de usuários, serviços e pedidos.

```text
React
   ↓
API REST
   ↓
Node.js + Express
   ↓
Prisma
   ↓
MongoDB
```

**Funcionalidades:**

- 🔐 Cadastro e login
- 🔑 Recuperação de senha
- ✉️ Verificação de e-mail
- 🛡️ Autenticação com JWT
- 🛒 Carrinho e pedidos
- 👤 Área administrativa
